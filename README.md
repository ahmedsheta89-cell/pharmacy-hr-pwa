# Pharmacy People — نظام موارد الصيدليات

تطبيق **PWA عربي** لإدارة الموارد البشرية وعمليات الصيدليات، مصمم لسطح المكتب والهواتف مع دعم كامل للاتجاه من اليمين إلى اليسار. يجمع التطبيق إدارة الموظفين والحضور والورديات والإجازات ومؤشرات الأداء والرواتب ضمن صلاحيات دقيقة تعتمد على الدور.

> هذا المستودع يحتوي على الشفرة المصدرية. لا تحفظ مفاتيح أو أسرار أو صادرات بيانات حقيقية داخل Git.

## المزايا الأساسية

| المجال | ما يقدمه التطبيق |
| --- | --- |
| الصلاحيات | أدوار المالك، مدير الفرع، مدير الموارد البشرية، الصيدلاني، والموظف، مع فرض الصلاحيات في الخادم والواجهة. |
| إدارة الموارد البشرية | ملفات الموظفين، التعديل، الأرشفة والاستعادة، سجل تدقيق تفصيلي، وربط الحسابات عبر اعتماد المالك. |
| التشغيل اليومي | حضور وانصراف، ورديات، إجازات، وتنبيهات وطلبات معلقة مرتبطة بنطاق الفرع. |
| الأداء والرواتب | KPIs، هياكل رواتب، مسيرات اعتماد متعددة المراحل، وتصدير XLSX للسجلات المصرح بها. |
| تجربة الهاتف وPWA | تثبيت كتطبيق، صفحة عدم اتصال، إشعار تحديث، اختصارات سفلية، حركة تراعي تقليل الحركة، ولقطة بيانات أساسية حديثة للعرض دون اتصال. |

## البدء محلياً

### المتطلبات

يتطلب المشروع **Node.js 22+** و**pnpm 10+** وقاعدة بيانات MySQL أو TiDB. تحتاج أيضاً إلى متغيرات بيئة المصادقة وقاعدة البيانات المناسبة لبيئتك.

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm dev
```

يفتح خادم التطوير على المنفذ الذي تعينه بيئتك. لا تثبت منفذاً ثابتاً داخل الشفرة.

### أوامر الجودة والإنتاج

```bash
pnpm check     # فحص TypeScript
pnpm test      # اختبارات Vitest
pnpm build     # بناء الواجهة والخادم للإنتاج
pnpm start     # تشغيل ناتج البناء
pnpm db:push   # توليد وتشغيل ترحيلات Drizzle في بيئة مهيأة
```

## متغيرات البيئة

لا ترفع ملفات `.env` إلى المستودع. يلزم إعداد متغيرات بيئتك الآمنة، ومنها:

| الفئة | أمثلة للمتغيرات |
| --- | --- |
| قاعدة البيانات | `DATABASE_URL` |
| المصادقة | `JWT_SECRET`، `OAUTH_SERVER_URL`، `VITE_OAUTH_PORTAL_URL` |
| تعريف التطبيق | `VITE_APP_ID`، `VITE_APP_TITLE`، `VITE_APP_LOGO` |
| خدمات المنصة | مفاتيح التخزين والخدمات المدمجة التي توفرها بيئة النشر الآمنة |

## ملاحظات أمنية

تُنفذ الصلاحيات في tRPC على الخادم؛ إخفاء عنصر واجهة لا يعد حماية بحد ذاته. تُخزن لقطة عدم الاتصال محلياً بشكل محدود، مرتبطة بالمستخدم الحالي، وتُمسح عند تسجيل الخروج. راجع [SECURITY.md](SECURITY.md) قبل مشاركة أي نسخة أو بيانات.
