# بيئة Cloudflare التجريبية

يحتوي هذا المجلد على مدخل Worker محدود لبيئة انتقال Pharmacy People. لا ينقل هذا الملف قاعدة بيانات MySQL أو OAuth أو صور العملاء، ولا يحوّل أي نطاق حي.

## النشر التجريبي

يُنشر Worker باسم `pharmacy-people-staging-api` وعلى نطاق `workers.dev` التجريبي. لا يُضبط أي مفتاح في `wrangler.jsonc`: تحفظ أسرار Supabase لاحقاً داخل إعدادات Cloudflare فقط، ولا تُسجل في Git.

## شرط التوسع

لا يضاف أي مسار أعمال قبل وجود ترحيل PostgreSQL مراجع وسياسات RLS واختبارات تفويض للدور والفرع. يظل `/health` المسار الوحيد المتاح حتى ذلك الحين.
